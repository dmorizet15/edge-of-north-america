# Photography drop-in folder

Real, licensed photographs go here. The experience renders elegant, tonal
placeholders until a file appears at the exact path a section expects — then it
swaps in automatically with a slow fade.

## How the swap works

Each frame is defined once in [`/content/photos.ts`](../../../content/photos.ts)
with its `src`, exact `location`, `searchTerms`, `aspectRatio`, `composition`,
and emotional `tone`. Drop a file at the `src` path and it replaces the
placeholder — no code changes needed.

## Rules

- **Real photography only.** No AI-generated scenery.
- **Never substitute one named location for another.** If Cape Spear isn't
  available, the placeholder stays until a real Cape Spear photo is sourced.
- **Fogo Island Inn** imagery requires a license or written permission.
- Recommended sources: Newfoundland & Labrador Tourism media assets, Wikimedia
  Commons, Unsplash, Pexels, licensed stock, official hotel media with permission.
